# 워드프레스 + 티스토리 같이 나가는 주제, 어떻게 돌릴까

## 지금 하시는 방식

```
집     글쓰기 선택 → 작성 → 일괄 임시저장
회사   워드프레스 들어가 8개 쭉 발행
       티스토리 들어가 8개 쭉 발행
```

**순서는 맞습니다.** 워드프레스가 먼저라 '자세히 보기' 가 안 죽습니다.
다만 세 가지가 걸립니다.

| | 문제 | 왜 |
| --- | --- | --- |
| 1 | 16개가 같은 시각에 몰림 | 사람이 쓴 블로그는 이렇게 안 올라옵니다 |
| 2 | 회사에서 16번 클릭 | 시간이 들고, 회사에서 하기 부담스럽습니다 |
| 3 | 시트 마무리를 빠뜨림 | 주소가 안 채워져 다음 글의 내부 링크가 약해집니다 |

3번이 실제로 일어났습니다. 71줄 중 61줄에 티스토리 주소가 비어
있었습니다. 발행은 다 하셨는데 시트가 모르고 있었습니다.

---

## 권하는 방식 — 워드프레스는 예약, 티스토리만 손으로

```
집     자동실행.bat 더블클릭
         ├ 글 만들기
         ├ 워드프레스 → 예약 발행 (07:00부터 45분 간격)
         └ 티스토리  → 임시저장

회사   티스토리만 들어가서 쭉 발행     ← 8번으로 줄어듦
       시트에서 마무리 2번
```

**워드프레스에 들어갈 일이 없어집니다.** 아침에 알아서 하나씩 올라갑니다.

### 왜 이 순서가 안전한가

워드프레스가 07:00~12:15 에 다 공개됩니다.
회사에서 티스토리를 여는 시각은 그보다 뒤입니다.
그러면 '자세히 보기' 를 눌렀을 때 워드프레스 글이 이미 살아 있습니다.

```
07:00  워드프레스 1번 공개
07:45  워드프레스 2번 공개
 ...
12:15  워드프레스 8번 공개
─────────────────────────
13:00  회사에서 티스토리 8개 발행   ← 링크가 전부 살아 있음
```

**티스토리를 오전 일찍 발행하시면 안 됩니다.** 아직 안 올라온
워드프레스 글을 가리키게 됩니다.

---

## 켜는 방법 — `.env` 에 두 줄

```
WORDPRESS_SCHEDULE_START=07:00
WORDPRESS_SCHEDULE_GAP_MINUTES=45
```

이 두 줄이 없으면 **지금과 똑같이** 초안으로만 올라갑니다.
켜기 전과 후에 달라지는 것은 워드프레스뿐입니다.

### 시각을 어떻게 잡나

`시작 시각` 이 이미 지났으면 **다음 날**로 넘어갑니다.
밤에 돌리시면 다음 날 아침으로 잡히고, 새벽에 돌리시면 그날
아침으로 잡힙니다.

| 글 개수 | 간격 | 끝나는 시각 (07:00 시작) |
| --- | --- | --- |
| 8개 | 45분 | 12:15 |
| 8개 | 60분 | 14:00 |
| 8개 | 90분 | 17:30 |

**45~60분을 권합니다.** 하루 안에 다 나가면서도 몰리지 않습니다.

### 한 카테고리만 먼저 해 보려면

```
WORDPRESS_SCHEDULE_CATEGORIES=최신이슈
```

최신이슈만 예약하고 나머지는 지금처럼 초안으로 둡니다.
며칠 돌려 보고 괜찮으면 이 줄을 지우면 전부 예약됩니다.

---

## 회사에서 하실 일 (5분)

### 1. 티스토리 발행

도메인별로 들어가서 임시저장된 것을 발행합니다.
**한 번에 다 누르지 마시고 몇 분씩 띄우면 더 좋습니다.**

### 2. 시트 메뉴 → `🔎 발행됐는지 확인`

블로그를 직접 보고 올라간 글을 발행완료 탭으로 옮깁니다.
**이걸 해야 주소가 시트에 적힙니다.**

### 3. 시트 메뉴 → `🔗 finwiz 링크 갱신`

찾은 주소를 링크관리에 적습니다.
**이걸 해야 다음 글이 이 글을 링크로 걸 수 있습니다.**

> 2번과 3번이 오늘까지 빠져 있던 단계입니다.
> 이것만 챙기시면 내부 링크가 저절로 두터워집니다.

---

## 집에서 하실 일

`자동실행.bat` 더블클릭 한 번. 그게 전부입니다.

돌아가는 동안 **크롬 창을 클릭하지 마시고 다른 창으로 넘어가지도
마세요.** 창이 뒤로 밀리면 죽는 경우가 있습니다.
(죽어도 이제 알아서 되살아나지만, 안 죽는 편이 낫습니다)

---

## 되돌리려면

`.env` 에서 `WORDPRESS_SCHEDULE_START` 줄을 지우면 됩니다.
다음 실행부터 예전처럼 초안으로만 올라갑니다.

이미 예약된 글은 워드프레스 글 목록에서 **예약됨** 으로 보입니다.
거기서 시각을 바꾸거나 초안으로 되돌릴 수 있습니다.

---

## 하루 흐름 요약

```
밤    집    자동실행.bat 더블클릭            (1번 클릭)
         └ 워드프레스는 예약, 티스토리는 임시저장

아침  —    워드프레스가 알아서 하나씩 공개     (할 일 없음)

낮    회사  티스토리 발행                     (8번 클릭)
           발행됐는지 확인                    (1번 클릭)
           finwiz 링크 갱신                  (1번 클릭)
```

전: 회사에서 16번 클릭 + 시트 마무리 없음
후: 회사에서 10번 클릭 + 시트가 항상 최신
