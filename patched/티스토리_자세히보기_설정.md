# 티스토리 → 워드프레스 '자세히 보기' 연결

## 지금 어떻게 되어 있나

**워드프레스와 티스토리를 둘 다 쓰는 카테고리는 이미 이렇게 돕니다.**
카테고리마다 따로 켜고 끄는 설정이 없습니다. 짝이 있으면 자동입니다.

| 카테고리 | 워드프레스 | 티스토리 | 자세히 보기 |
| --- | --- | --- | --- |
| 최신이슈 | seaga.co.kr | seaga.tistory.com | **됩니다** |
| 정책지원 | seaga.co.kr | seaga5.tistory.com | **됩니다** |
| 신장정신 | saega2.seaga.co.kr | seaga2.tistory.com | **됩니다** |
| 웰빙 | bodybalance-labo.com | seaga2.tistory.com | **이번에 추가** |
| 대출관련 (finwiz) | 없음 | finwiz.tistory.com | 걸 곳이 없음 |
| 꿈해몽 | 없음 | seaga4.tistory.com | 걸 곳이 없음 |

아래 두 줄은 워드프레스 글이 아예 없습니다. 그래서 자세히 보기가
붙지 않습니다. 대신 꿈해몽은 **지난 꿈 글끼리** 서로 링크를 겁니다.

---

## 어떤 순서로 도나

```
python blog_content_pipeline.py
   └ 글을 두 개 만듭니다
        기본 칸(D~F)     → 워드프레스 글 (자세한 설명)
        티스토리 칸(J~L)  → 티스토리 글 (짧고 실천 위주, 다른 제목)

python blog_publish_pipeline.py
   ├ ① 워드프레스에 임시저장  →  주소가 생기고 시트에 적힙니다
   └ ② 티스토리에 임시저장
        ①의 주소로 '자세히 보기' 를 본문에 넣습니다
```

**순서는 프로그램이 알아서 지킵니다.** 워드프레스를 다 끝낸 뒤에
티스토리를 시작합니다. `자동실행.bat` 그대로 쓰시면 됩니다.

자세히 보기는 본문의 `최종 정리하면,` 바로 앞에 이렇게 들어갑니다.

> 여기까지 읽어도 궁금한 부분이 남는다면 **자세히 보기**에서
> 조금 더 구체적인 내용을 확인해 보세요.

## ⚠️ 꼭 지킬 것 — 워드프레스를 먼저 공개 발행하세요

시트의 결과 URL 칸을 보면 이렇게 생겼습니다.

```
https://seaga.co.kr/?p=3248
```

이건 **워드프레스가 초안일 때 주는 주소**입니다.
글을 공개 발행하면 이 주소가 최종 주소로 알아서 넘어갑니다.
그래서 링크 자체는 그대로 둬도 됩니다.

**다만 워드프레스가 초안인 동안에는 이 주소가 열리지 않습니다.**
티스토리를 먼저 공개해 버리면, 독자가 자세히 보기를 눌렀을 때
빈 화면을 봅니다.

```
✅ 워드프레스 공개  →  티스토리 공개
❌ 티스토리 공개    →  워드프레스는 아직 초안   ← 죽은 링크
```

이제 프로그램이 초안 주소를 발견하면 파워셸에 이렇게 알려 줍니다.

```
'자세히 보기' 가 워드프레스 초안 주소입니다: https://seaga.co.kr/?p=3248
  워드프레스 글을 먼저 공개 발행해 주세요. 그 전에는 이 링크가 열리지 않습니다.
```

## 웰빙을 새로 여는 방법

웰빙만 아직 티스토리 짝이 없었습니다. 세 군데를 맞춰 주면 됩니다.

### ① `publish_targets.json` (사장님 컴퓨터에만 있는 파일)

`extra_categories` 안에 웰빙을 넣습니다.

```json
"extra_categories": {
  "웰빙": [
    {
      "platform": "tistory",
      "url": "https://seaga2.tistory.com",
      "blog_name": "seaga2"
    }
  ]
}
```

> 이미 `extra_categories` 가 있으면 **그 안에 웰빙 줄만** 끼워 넣으세요.
> 파일 전체를 덮어쓰면 다른 블로그 설정이 사라집니다.
> 쉼표를 빠뜨리면 프로그램이 파일을 못 읽습니다.

### ② Apps Script `260816글쓰기` 의 카테고리표

이미 넣어 뒀습니다. 블로그를 바꾸시려면 이 줄만 고치면 됩니다.

```js
'웰빙': {
  워드프레스: 'bodybalance-labo.com',
  티스토리: 'seaga2.tistory.com',   // ← ①과 똑같아야 합니다
  ...
}
```

### ③ 티스토리에 카테고리 만들기

seaga2.tistory.com 관리 → 카테고리 관리.
없는 이름은 알아서 건너뛰므로 하나만 만드셔도 됩니다.

```
건강 음식 관련     ← 식단·영양·음식 글
운동 관련          ← 운동·다이어트 글
수면 관련          ← 수면·불면 글
건강 정보          ← 그 밖에
```

---

## 왜 seaga2 를 권하나

| 블로그 | 지금 주제 | 웰빙을 넣으면 |
| --- | --- | --- |
| **seaga2** | 신장·불안·공황 (건강) | **주제가 한 덩어리로 모입니다** |
| seaga | 최신이슈 (잡다) | 이슈 블로그가 더 흐려집니다 |
| seaga5 | 정책지원 | 결이 다릅니다 |

신장·불안을 보러 온 사람은 식단·운동·수면도 봅니다.
한 블로그에 같은 주제를 모으면 구글이 알아봅니다.

## 첫 글에서 확인할 것

- [ ] 티스토리 글 제목이 워드프레스 글과 **다른가** (같으면 중복 문서가 됩니다)
- [ ] 티스토리 카테고리가 맞게 잡혔는가
- [ ] **워드프레스를 먼저 공개 발행한 뒤**, 자세히 보기를 눌렀을 때 그 글로 가는가
- [ ] 대표이미지가 걸렸는가

## 되돌리려면

`publish_targets.json` 에서 웰빙의 `extra_categories` 를 지우고,
카테고리표의 `티스토리: 'seaga2.tistory.com'` 을 `티스토리: null` 로
바꾸면 예전처럼 워드프레스만 씁니다.
