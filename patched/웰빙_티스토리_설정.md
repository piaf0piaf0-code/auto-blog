# 웰빙을 티스토리에도 올리기

## 무엇이 달라지나

지금까지 웰빙은 `bodybalance-labo.com` 한 곳에만 올라갔습니다.
이제 티스토리에도 같이 올리고, 티스토리 글에서 워드프레스 글로
**자세히 보기** 링크를 걸 수 있습니다.

```
티스토리 글  ──자세히 보기──▶  bodybalance-labo.com 글
(짧고 실천 위주)                (길고 자세한 설명)
```

최신이슈가 이미 이렇게 돌고 있습니다. 같은 방식입니다.

---

## 어느 블로그에 넣나 — seaga2.tistory.com 을 권합니다

| 블로그 | 지금 쓰는 주제 | 웰빙을 넣으면 |
| --- | --- | --- |
| **seaga2.tistory.com** | 신장·불안·공황 (건강) | **주제가 한 덩어리로 모입니다** |
| seaga.tistory.com | 최신이슈 (잡다) | 이슈 블로그가 더 흐려집니다 |
| seaga5.tistory.com | 정책지원 | 결이 다릅니다 |

`seaga2` 는 이미 건강 블로그입니다. 신장·불안을 보러 온 사람은
식단·운동·수면도 같이 봅니다. 한 블로그에 같은 주제를 모으면
구글이 "이 블로그는 건강을 다루는 곳" 이라고 알아봅니다.

바꾸고 싶으시면 아래 두 군데의 주소만 고치면 됩니다.

---

## 1단계 · `publish_targets.json` 에 티스토리 추가

파이썬 폴더의 `publish_targets.json` 을 메모장으로 엽니다.
`extra_categories` 안에 `웰빙` 을 넣습니다.

```json
{
  "categories": {
    "웰빙": {
      "platform": "wordpress",
      "url": "https://bodybalance-labo.com"
    }
  },
  "extra_categories": {
    "웰빙": [
      {
        "platform": "tistory",
        "url": "https://seaga2.tistory.com",
        "blog_name": "seaga2"
      }
    ]
  }
}
```

> 이미 `categories` 와 `extra_categories` 가 있으면 **그 안에 웰빙 줄만**
> 끼워 넣으세요. 파일 전체를 덮어쓰면 다른 블로그 설정이 사라집니다.
> 쉼표를 빠뜨리면 프로그램이 파일을 못 읽습니다.

## 2단계 · Apps Script `260816글쓰기` 덮어쓰기

`카테고리표` 의 웰빙에 티스토리 주소를 넣어 뒀습니다.

```js
'웰빙': {
  워드프레스: 'bodybalance-labo.com',
  티스토리: 'seaga2.tistory.com',
  ...
}
```

다른 블로그로 하시려면 이 줄만 고치면 됩니다.
**1단계의 주소와 똑같아야 합니다.**

## 3단계 · 파이썬 파일 2개 덮어쓰기

- `blog_content_pipeline.py` — 웰빙도 티스토리용 글을 따로 만듭니다
- `blog_tistory_browser_draft.py` — 웰빙 글의 티스토리 카테고리를 고릅니다

## 4단계 · 티스토리에 카테고리 만들기

seaga2.tistory.com 관리 → 카테고리 관리에서 아래 중 **하나 이상**을
만들어 두세요. 없는 이름은 알아서 건너뜁니다.

```
건강 음식 관련     ← 식단·영양·음식 글
운동 관련          ← 운동·다이어트 글
수면 관련          ← 수면·불면 글
건강 정보          ← 그 밖에
```

넷 다 만들면 글 주제에 따라 알아서 나뉩니다.
하나만 만들면 전부 그 하나로 갑니다.

---

## 발행은 어떤 순서로 도나

평소와 똑같습니다. 순서가 중요합니다.

```
python blog_content_pipeline.py
   └ 워드프레스용 글 + 티스토리용 글을 따로 만듭니다
        기본 칸(D~F)   → 워드프레스 글
        티스토리 칸(J~L) → 티스토리 글 (다른 제목, 다른 소제목)

python blog_publish_pipeline.py
   ├ ① bodybalance-labo.com 에 임시저장 → 주소가 생깁니다
   └ ② seaga2.tistory.com 에 임시저장
        이때 ①에서 생긴 주소로 '자세히 보기' 를 본문에 넣습니다
```

**워드프레스가 먼저 올라가야 자세히 보기 주소가 생깁니다.**
`blog_publish_pipeline.py` 가 그 순서를 알아서 지킵니다.
`자동실행.bat` 을 쓰셔도 됩니다.

## 자세히 보기가 어떻게 들어가나

티스토리 본문의 `최종 정리하면,` 바로 앞에 이렇게 들어갑니다.

> 여기까지 읽어도 궁금한 부분이 남는다면 **자세히 보기**에서
> 조금 더 구체적인 내용을 확인해 보세요.

---

## 확인할 것

첫 글을 올린 뒤 눈으로 보세요.

- [ ] 티스토리 글 제목이 워드프레스 글과 **다른가** (같으면 중복 문서로 취급됩니다)
- [ ] 티스토리 카테고리가 맞게 잡혔는가
- [ ] `자세히 보기` 링크를 누르면 bodybalance-labo.com 글로 가는가
- [ ] 대표이미지가 걸렸는가

## 되돌리려면

`publish_targets.json` 의 `extra_categories` 에서 웰빙 부분을 지우고,
`카테고리표` 의 `티스토리: 'seaga2.tistory.com'` 을 `티스토리: null` 로
바꾸면 예전처럼 워드프레스만 씁니다.
