# 서치콘솔 성적표 설치 (15분, 한 번만)

## 1. 파일 넣기

앱스스크립트 편집기(확장 프로그램 → Apps Script)에서

1. 왼쪽 `파일` 옆 **＋ → 스크립트** → 이름을 `서치콘솔` 로
2. 안을 비우고 `서치콘솔.gs` 를 통째로 붙여넣기 → **633줄**인지 확인
3. 같은 방법으로 새 파일 `트렌드` → `트렌드.gs` 붙여넣기 → **322줄**
4. `260816글쓰기.gs` 도 새 파일로 바꾸기 → **2678줄**인지 확인

## 2. 권한 한 줄 넣기 — 가장 중요

서치콘솔을 읽으려면 권한 목록에 한 줄이 있어야 합니다.

1. 편집기 왼쪽 **톱니바퀴(프로젝트 설정)**
2. **"편집기에서 'appsscript.json' 매니페스트 파일 표시"** 체크
3. 편집기로 돌아와 `appsscript.json` 열기
4. 이 덩어리를 넣습니다. 이미 있는 줄(`timeZone` 등)은 그대로 두고 **`oauthScopes` 만 더합니다.**

```json
  "oauthScopes": [
    "https://www.googleapis.com/auth/spreadsheets",
    "https://www.googleapis.com/auth/script.container.ui",
    "https://www.googleapis.com/auth/script.external_request",
    "https://www.googleapis.com/auth/script.scriptapp",
    "https://www.googleapis.com/auth/webmasters.readonly"
  ]
```

앞 네 줄은 **지금 쓰시는 기능(시트·사이드바·링크 확인·자동 실행)이 원래 쓰던 권한**입니다.
이 목록을 적으면 적힌 것만 허용되므로, 다섯 줄을 **전부** 넣어야 기존 기능이 안 멈춥니다.

완성된 모양은 저장소의 `appsscript/appsscript.json` 과 같습니다.
이미 `oauthScopes` 가 있으시면 빠진 줄만 더하세요.

5. 저장(Ctrl+S)

## 3. 처음 한 번 허용

1. 시트를 새로고침
2. 메뉴 `블로그 자동화` → **📊 서치콘솔 성적표 받기**
3. 권한 창이 뜹니다 → 계정 선택
4. **"Google에서 확인하지 않은 앱"** 이 뜨면 → **고급** → **(프로젝트 이름)(으)로 이동** → **허용**
   - 회원님이 직접 만든 스크립트라 구글 심사를 안 거쳤다는 뜻입니다. 정상입니다.
5. 메뉴를 **한 번 더** 누릅니다 → 성적표 알림창이 뜨면 성공

## 4. 매일 자동으로

메뉴 → **⏰ 매일 아침 자동 (성적표·트렌드)** → 끝.
매일 아침 7시쯤 구글 서버에서 성적표를 받고, 구글 트렌드에서 우리 분야 검색어를 건져 `TR_후보` 탭에 올립니다. **PC가 꺼져 있어도 됩니다.**
끄려면 **⏹ 자동 받기 끄기**.

## 생기는 탭 다섯 개

| 탭 | 보는 법 |
|---|---|
| **SC_블로그별** | 블로그마다 한 줄. **'한 번도 안 나온 글'** 비율이 높으면 새 글보다 색인·품질이 먼저 |
| **SC_할일** | 돈 되는 순서로 손볼 글. `순위 보강` / `제목 개선` / `합치기` |
| **SC_싸우는글** | 같은 검색어에 내 글이 둘 이상 — 하나로 합칠 곳 |
| **SC_글별** | 글 하나하나의 성적 |
| **SC_기록** | 날마다 한 줄씩 쌓임. 한 달 뒤 추세가 보입니다 |

## 서치콘솔에 없는 블로그가 있다고 나오면

알림창 아래에 `서치콘솔에 없는 내 블로그` 가 나옵니다. 그 블로그는 성적을 알 수 없습니다.

**티스토리 등록:**
1. 서치콘솔 → 속성 추가 → **URL 접두어** → `https://블로그이름.tistory.com/`
2. 확인 방법 **HTML 태그** → `<meta name="google-site-verification" ...>` 복사
3. 티스토리 관리 → 꾸미기 → **스킨 편집 → html 편집** → `<head>` 바로 아래 붙여넣기 → 적용
4. 서치콘솔로 돌아와 **확인**
5. 사이트맵 → `sitemap.xml` 제출

**다른 구글 계정으로 등록돼 있다면:** 그 서치콘솔 → 설정 → 사용자 및 권한 → 이 시트를 연 계정을 **전체** 권한으로 추가.

## 안 될 때

| 알림창 | 뜻 |
|---|---|
| `권한이 없습니다` | 2번 권한 줄이 빠졌거나, 3번 허용을 안 하셨거나, 계정이 다름 |
| `볼 수 있는 속성이 없습니다` | 이 시트를 연 계정에 서치콘솔 속성이 없음 → 위 "다른 구글 계정" 참고 |
| 메뉴에 📊 가 안 보임 | 시트 새로고침. 그래도 없으면 `서치콘솔` 파일이 안 들어간 것 |

## 트렌드에서 건지기

구글 트렌드 한국 인기 검색어에서 **우리 분야에 걸리는 것만** 건집니다.

| 판정 | 예 | 처리 |
|---|---|---|
| ✔ 씀 | 청년미래적금 → 대출관련 | `TR_후보` 탭에 올림 |
| 건너뜀 | 축구중계, 영화, 선수 이름 | 버림 — 언론사가 1위, 며칠이면 끝 |
| ✕ 안 씀 | ○○ 사망, 별세, 사고, 열애, 논란 | 버림 — 뉴스 제목까지 보고 거릅니다 |
| · 이미 있음 | 오늘작성·발행완료에 있는 키워드 | 버림 |

쓰는 법: `TR_후보` 탭에서 쓸 것만 **오늘작성으로** 칸을 체크 → 메뉴 **➡️ 체크한 트렌드 오늘작성으로**.
오늘작성에 들어가면서 롱테일도 자동으로 채워져 바로 `글쓰기대기` 가 됩니다.

우리 분야 말(적금·대출·지원금·연금·건강…)은 `트렌드.gs` 위쪽의 `TR분야표` 에,
버리는 말(사망·사고·열애…)은 `TR버림말` 에 있습니다. 더하고 싶은 말이 있으면 알려주세요.
