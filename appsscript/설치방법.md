2. 왼쪽 **파일** 옆의 **+** → **스크립트**
3. 이름을 **`글쓰기`** 라고 씁니다
4. 새로 만들어진 파일의 내용을 **전부 지웁니다** (Ctrl+A → Delete)
5. 이 폴더의 **`260816글쓰기.gs`** 를 메모장으로 열어 **전부 복사**해서 붙여넣습니다
6. **저장**(💾)

> 기존 `Code.gs` 는 손대지 않습니다. 새 파일에만 붙여넣습니다.

## 3단계 · 메뉴 확인

`260816글쓰기.gs` 안에 `onOpen` 이 들어 있습니다. 이것이 `블로그 자동화` 메뉴를
만듭니다. 기존 선택완료·삭제 기능이 살아 있으면 알아서 메뉴에 넣어 주고,
없으면 그 줄만 빠집니다.

```js
function onOpen() {
  var 메뉴 = SpreadsheetApp.getUi().createMenu('블로그 자동화');
  if (typeof moveSelectedToToday === 'function') { ... }
  if (typeof deleteUnselectedRows === 'function') { ... }
  메뉴.addItem('✍️ My GPT 글쓰기', '글쓰기화면열기');
  메뉴.addToUi();
}
```

> ## ⛔ onOpen 은 프로젝트 전체에 하나만
>
> 다른 파일(`Code.gs` 등)에도 `onOpen` 이 있으면 둘 중 하나만 살아남고
> 나머지 메뉴가 **통째로 사라집니다.** 다른 파일의 `onOpen` 은 지우세요.
>
> 같은 이유로 **이 코드를 두 파일에 넣으면 안 됩니다.** 같은 이름이
> 두 번 선언돼서 프로젝트 전체가 멈춥니다.

## 시트는 안 건드려도 됩니다

기존 열(`원본 메인 키워드`, `SEO 최적화 제목`, `HTML 본문 내용` 등)은
**하나도 건드리지 않습니다.**

저장할 열이 없으면 **맨 뒤에 자동으로** 만듭니다.

```
[기존] 원본 메인 키워드 | 카테고리 | 워드프레스 롱테일 | SEO 최적화 제목 |
       메타 디스크립션 및 태그 | HTML 본문 내용 | 작업 상태 | 대표 링크/결과 URL
[추가] WP제목 | WP메타설명 | WP태그 | WP본문 |
       TS제목 | TS메타설명 | TS태그 | TS본문 | 포커스키워드 | 출처정리
```

열 이름도 알아서 찾습니다 — `원본 메인 키워드` → 키워드,
`작업 상태` → 상태 로 인식합니다.

## 자주 겪는 일

**메뉴에 안 보임**
시트를 새로고침(F5)하세요. 그래도 없으면 3단계에서 저장을 안 했거나,
`.addToUi();` 아래에 넣었을 수 있습니다.

**"'오늘작성' 탭을 찾지 못했습니다"**
`글쓰기` 파일 맨 위의 `var 탭이름 = '오늘작성';` 에서 따옴표 안을
실제 탭 이름으로 바꾸세요.

**"모르는 카테고리입니다"**
카테고리 칸 글자가 표와 달라서 그렇습니다.
쓸 수 있는 값: `최신이슈`, `정책지원`, `대출관련`, `신장정신`, `웰빙`, `꿈해몽`

**"대괄호 제목을 찾지 못했습니다"**
My GPT 답을 일부만 복사한 경우입니다. 처음부터 끝까지 복사하세요.
계속 이러면 My GPT 지침에 `MY_GPT_OUTPUT_SPEC.md` 의 출력 형식을 넣으세요.

**"이미 선언되었습니다" 같은 빨간 오류**
기존 `Code.gs` 에 같은 이름의 함수나 변수가 있는 경우입니다.
그 오류 메시지를 그대로 알려 주시면 이름을 바꿔 드리겠습니다.

| `finwiz_링크관리` | 글 197개(기존글 30 + 계획 167)의 제목과 **주소** |

이 버튼은 몇 번을 눌러도 안전합니다. **이미 적힌 주소와 작성상태는 지우지 않습니다.**
로드맵 엑셀이 바뀌면 `finwiz자료.gs` 만 새로 받아 바꿔 넣고 다시 누르시면 됩니다.

## 매번 · 글 한 편 쓰기

**블로그 자동화** → **🧭 finwiz 순서대로 글쓰기**

1. 맨 위에 **다음에 쓸 글**이 나옵니다. 순서대로 위에서부터 고르시면 됩니다.
2. 고르면 **이 글에 들어갈 내부 링크 3개**가 먼저 보입니다.
3. **📋 복사하고 My GPT 열기** → 붙여넣고 Enter
4. 받은 글을 전부 복사해 **2단계 칸**에 붙여넣고 **확인하고 저장**

저장하면 `오늘작성` 탭에 **발행대기**로 새 행이 생깁니다.
그다음은 평소와 똑같이 발행 도구가 티스토리에 올립니다.

## 발행 뒤 · 링크가 저절로 이어집니다

**🔎 발행됐는지 확인** 을 누르면, 글 주소를 찾아내면서
그 주소를 `finwiz_링크관리` 에 자동으로 적습니다.
(따로 누르고 싶으면 **🔗 finwiz 링크 갱신**)

주소가 적히는 순간부터 **다음 글이 그 글을 링크로 겁니다.**

```
1번 글 발행 → 주소 기록
2번 글 쓸 때 → 1번 글 링크가 요청문에 들어감
3번 글 쓸 때 → 1·2번 중 관련 있는 글 링크가 들어감
...
```

**아직 안 쓴 글의 링크는 절대 넣지 않습니다.**
그래서 나중에 이미 발행한 글을 되돌아가 고칠 일이 없습니다.

## 링크를 고르는 순서

1. 로드맵(`05_링크관리`)이 지정한 관련글 1~3 중 **주소가 이미 있는 것**
2. 모자라면 **같은 주제 묶음**에서 주소가 있는 글 (순번이 가까운 것부터)
3. 그래도 모자라면 **키워드가 겹치는** 글

167편 전체를 돌려 본 결과 **모든 글이 링크 3개를 받습니다.**
(로드맵이 지정한 493건 중 342건이 그대로 쓰이고, 나머지는 2·3번 규칙이 채웁니다)

## 봇이 링크를 빠뜨려도 괜찮습니다

요청문에 링크를 넣어 달라고 적지만, 봇이 빼먹는 일이 있습니다.
저장할 때 본문을 검사해서 **빠진 링크는 `함께 보면 좋은 글` 목록으로**
`최종 정리하면` 바로 앞에 자동으로 넣습니다.

## 제목은 로드맵 제목으로 고정됩니다

봇이 제목을 바꿔 써도 저장할 때 로드맵 제목으로 되돌립니다.
발행 확인이 **제목으로** 글 주소를 찾기 때문입니다.
제목이 흔들리면 주소를 못 찾고, 그러면 다음 글이 링크를 못 겁니다.

## ② 사실카드 — 같은 숫자를 167번 찾지 않습니다

**`🧾 사실카드`** 는 주제마다 한 장씩 만드는 숫자 표입니다.

글을 열었을 때 그 주제의 카드가 없으면 화면에 **`🧾 사실카드 먼저 만들기`**
버튼이 뜹니다. 누르면 요청문이 나오고, 받은 표를 붙여넣으면
`finwiz_사실카드` 탭에 들어갑니다. **주제당 한 번, 5분.**

그다음부터 그 주제의 모든 글 요청문에 이 숫자가 자동으로 들어갑니다.

| 이렇게 하면 | 이유 |
| --- | --- |
| 조사 167번 → 14번 | 주제가 14개뿐입니다 |
| 글끼리 숫자가 안 어긋남 | 전부 같은 카드를 봅니다 |
| 금리가 바뀌면 칸 하나만 고침 | 이후 글에 바로 반영됩니다 |

기준일에서 **90일**이 지나면 요청문에 "원문에서 바뀐 게 없는지 먼저
확인하라" 는 문장이 자동으로 붙습니다.
**블로그 자동화 → 🧾 finwiz 사실카드 점검** 으로 어느 주제가 오래됐는지 볼 수 있습니다.

## ③ 저장할 때 자동 검사 (돈이 들지 않습니다)

**저장을 막는 것** — 고치기 전까지 발행 대기로 넘어가지 않습니다.

- `무조건 승인`, `100% 가능`, `승인 확정`, `누구나 가능`, `신용 상관없이`
- `작업대출`, `무서류 대출`, `당일 무조건`
- 전화번호, `지금 바로 신청하세요` 같은 유도 문구
- `2024년 기준` 처럼 지난 연도를 기준으로 적은 것

> 애드센스 금융 정책에 걸리면 finwiz 전체 광고가 제한될 수 있습니다.
> 한 편 때문에 블로그 전체를 잃지 않으려고 아예 막습니다.
> 걸리면 시트 상태가 `검사실패` 로 남습니다.

**알려만 주는 것** — 저장은 되고, 화면에 노란 칸으로 뜹니다.

- 사실카드와 숫자가 다를 때 (그 항목을 말하면서 다른 값을 쓴 경우만)
- 금액·금리가 있는데 본문에 링크가 하나도 없을 때
- **소제목이 이미 쓴 글과 60% 이상 겹칠 때** — 167편이 같은 주제라
  이게 제일 위험합니다. 서로 검색순위를 깎아먹습니다.
- 소제목이 3개 미만일 때
