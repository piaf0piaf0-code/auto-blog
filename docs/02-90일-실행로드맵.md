# 02. 90일 실행 로드맵

수익은 "글 쓰기"가 아니라 **검색 신뢰 자산 쌓기**에서 나온다. 자산은 보통
3~6개월의 시차를 두고 트래픽으로 돌아온다. 그래서 90일은 *수익 폭발*이
아니라 *수익이 시작되는 구조*를 만드는 기간이다.

---

## 0주차: 정리와 세팅 (리스크 제거 먼저)

- [ ] **아비트라지 구조 폐기** — `sa.seaga.co.kr`, `01.sa.seaga.co.kr`의
      브리지/연결 구조 중단. 정상 콘텐츠로 전환하거나 내린다.
      (승인된 계정을 지키는 게 최우선이다.)
- [ ] 핵심 2개 사이트(`finwiz`, `bodybalance-labo`)에 **Google Search
      Console + GA4** 연결 확인.
- [ ] 워드프레스 사이트에 **Application Password** 발급 → `.env` 작성.
- [ ] 이 저장소 세팅: `pip install -r requirements.txt`, `.env` 작성, 테스트 실행.

---

## 1단계 (1~3주차): 키워드 자산 지도 만들기

목표: "무슨 글을 쓸지"를 감이 아니라 데이터로 정한다.

- [ ] 핵심 분야별로 키워드 기회 발굴
  ```bash
  python -m src.run_pipeline keywords --niche "대출" --count 30
  python -m src.run_pipeline keywords --niche "신장병 건강관리" --count 30
  ```
- [ ] 결과를 **고단가 × 저경쟁 × 검색의도 명확** 기준으로 상위 20개 선별
      (→ `docs/03-키워드-선정-가이드.md`).
- [ ] **토픽 클러스터** 2개 설계: 예) "전세자금대출"을 중심으로
      필러글 1 + 세부글 12. 건강도 1개.
- [ ] Search Console에서 **이미 노출되는데 순위가 낮은(11~30위) 키워드**를
      찾아 우선 보강 목록에 추가(가장 빠른 성과).

## 2단계 (4~8주차): 클러스터 콘텐츠 채우기

목표: 첫 클러스터를 완성해 "이 주제 전문가" 신호를 만든다.

- [ ] 주당 3~5개 페이스로 초안 생성 → 검수 → 발행
  ```bash
  python -m src.run_pipeline brief --keyword "전세자금대출 조건 2026"
  # drafts/ 에 생성됨 → 사람이 검수·보강·사실확인
  python -m src.run_pipeline publish --file drafts/xxx.md --site bodybalance
  ```
- [ ] 각 글은 **품질 체크리스트(04번 문서) 통과 후에만 공개**.
- [ ] 필러글 ↔ 세부글 **내부링크** 연결(스크립트가 후보 제안).
- [ ] 계산기 사이트의 유틸 페이지 → 관련 고단가 글로 내부링크.

## 3단계 (9~12주차): 측정·이중화·확장

목표: 무엇이 먹히는지 보고, 먹히는 쪽을 키운다.

- [ ] Search Console 데이터로 **순위 오르는 글 / 죽은 글** 분류.
- [ ] 상위 진입 글은 **추가 섹션·최신화**로 1페이지 굳히기.
- [ ] 두 번째 클러스터 시작.
- [ ] **계정 리스크 분산**: 모든 달걀을 한 애드센스 계정에 담지 않도록
      트래픽·수익을 여러 승인 자산에 분산.

---

## 성과 기대치 (정직하게)

| 시점 | 현실적 기대 |
|------|-------------|
| 1~2개월 | 수익 변화 거의 없음(색인·신뢰 쌓이는 중). 정상이다. |
| 3~4개월 | 첫 클러스터 키워드들이 1~2페이지 진입 시작, 수익 첫 상승 |
| 6개월 | 클러스터 2~3개가 트래픽 견인, 의미 있는 월수익 구간 진입 |
| 9~12개월 | 고단가 클러스터 누적 + 이중화로 목표 구간 도전 |

월 2천만원은 "빠른 길"이 아니라 **고단가 클러스터를 여러 개 쌓았을 때**
도달하는 지점이다. 핵심은 *멈추지 않고 옳은 방향으로 쌓는 것*.
