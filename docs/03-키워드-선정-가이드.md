# 03. 키워드 선정 가이드

좋은 글을 잘못된 키워드로 쓰면 아무도 안 본다. 키워드 선정이 수익의 80%다.

## 1) 우리가 노리는 키워드의 3가지 조건

1. **고단가 (High RPM/CPC)** — 대출·보험·세금·건강·법률처럼 광고주가 돈을
   많이 쓰는 분야. 같은 1,000뷰라도 수익이 10배.
2. **저경쟁 (Low competition)** — 거대 사이트·금융사 공식 페이지가
   도배하지 않은 틈새. 신생 블로그가 1페이지 갈 수 있어야 한다.
3. **검색 의도 명확** — 그 검색어를 친 사람이 무엇을 원하는지 분명해야
   "그 답을 가장 잘 주는 글"을 만들 수 있다.

## 2) 검색 의도(Search Intent) 4분류

| 의도 | 예시 | 수익 관점 |
|------|------|-----------|
| 정보형 (Informational) | "전세자금대출 조건" | 트래픽 큼, 애드센스 핵심 |
| 상업조사형 (Commercial) | "전세대출 금리 비교" | 단가 높음, 전환 가능 |
| 거래형 (Transactional) | "전세대출 신청" | 단가 최고, 경쟁 셈 |
| 탐색형 (Navigational) | "OO은행 전세대출" | 보통 우리 대상 아님 |

→ **정보형 + 상업조사형의 롱테일(3~4 단어)** 이 신생 자산의 스윗스팟.

## 3) 롱테일이 답인 이유

- "대출"(검색량 거대, 경쟁 지옥) ❌
- "신혼부부 전세자금대출 소득기준 2026" (검색량 중간, 경쟁 약함, 의도 명확) ✅

롱테일 여러 개가 모여 **토픽 클러스터**가 되면, 메인 키워드까지 자연스럽게
순위가 따라 오른다.

## 4) 도구 사용법

```bash
# 분야(seed)를 넣으면 Claude가 고단가·저경쟁 후보를 점수와 함께 제안
python -m src.run_pipeline keywords --niche "전세자금대출" --count 30
```

출력 각 항목에는 다음이 포함된다:
- `keyword` — 추천 키워드(롱테일)
- `intent` — 검색 의도 분류
- `value_score` (1~10) — 추정 단가/수익 가치
- `competition_score` (1~10) — 추정 경쟁 강도(낮을수록 좋음)
- `opportunity_score` — 종합 우선순위 (가치 높고 경쟁 낮을수록 높음)
- `content_angle` — 어떤 각도로 써야 1등 하는지
- `cluster` — 어느 토픽 클러스터에 속하는지

> ⚠️ Claude의 점수는 **학습된 지식 기반 추정치**다. 발행 우선순위를 빠르게
> 잡는 용도이며, 진짜 검색량/경쟁은 아래로 검증한다.

## 5) 무료 검증 루틴 (추정 → 사실 확인)

1. **Google Search Console** — 내 사이트가 이미 노출되는 쿼리 중
   순위 11~30위인 것 = "조금만 보강하면 1페이지" → 최우선.
2. **구글 자동완성 / 연관검색어 / "사람들이 많이 묻는 질문(PAA)"** —
   실제 사람들이 치는 변형과 하위 질문을 수집.
3. **실제 구글 검색해서 1페이지 확인** — 상위가 전부 대형 금융사/뉴스면
   경쟁 과함 → 더 좁은 롱테일로 이동. 개인 블로그/커뮤니티가 보이면 기회.
4. (선택) **구글애즈 키워드 플래너** — 광고 계정 있으면 실제 검색량/CPC 확인.

## 6) 클러스터 설계 예시 (전세자금대출)

- **필러글(허브):** "전세자금대출 완벽정리 — 조건·한도·금리·신청"
- **세부글(스포크) 12개:**
  - 신혼부부 전세자금대출 소득기준
  - 청년 전세자금대출 종류 비교
  - 전세자금대출 한도 계산하는 법
  - 전세대출 금리 낮추는 5가지 방법
  - 전세자금대출 거절 사유와 대처
  - … (각각 롱테일 1개씩)
- 모든 세부글 → 필러글로 내부링크, 필러글 → 세부글로 내부링크.
