# 04. 콘텐츠 품질 체크리스트

이 저장소는 AI로 *초안*을 만든다. 하지만 **사람 검수 없이 발행하면**
2024년 이후 구글의 대량생성 콘텐츠 페널티에 걸린다. 아래 체크리스트를
통과한 글만 `draft`에서 공개로 전환한다.

## A. 발행 전 필수 체크 (하나라도 No면 공개 금지)

- [ ] **검색 의도 충족** — 이 키워드로 온 사람의 질문에 첫 화면에서 답하는가?
- [ ] **사실 검증** — 숫자·조건·날짜·법규를 1차 출처(정부/은행 공식)로 확인했나?
      (대출·건강은 부정확하면 신뢰 0 + YMYL 페널티 위험)
- [ ] **고유한 가치** — 다른 1페이지 글에 없는 정보/표/예시/경험이 최소 1개?
- [ ] **사람이 손댐** — AI 초안 그대로가 아니라, 도입·예시·결론을 사람이 보강했나?
- [ ] **최신성** — 연도·금리·기준이 현재(2026) 기준인가?
- [ ] **가독성** — 소제목, 표, 리스트로 스캔 가능한가? 모바일에서 읽히나?
- [ ] **내부링크** — 같은 클러스터의 필러/스포크 글로 2~4개 연결했나?
- [ ] **메타** — 제목 태그(50~60자), 메타설명(120~155자)이 키워드 포함하고 매력적인가?

## B. YMYL 주의 (대출·건강·금융·법률)

구글은 "돈·건강에 영향을 주는 주제(YMYL)"를 특히 엄격하게 평가한다.

- 작성자/감수자 정보, 출처 링크, 면책 문구를 넣어 **신뢰(E-E-A-T)** 신호를 준다.
- 건강 글: "의학적 조언이 아니며 전문의 상담 권장" 류 면책.
- 대출 글: "조건은 금융사·시점에 따라 다르며 공식 확인 필요" 명시 + 공식 링크.

## C. 절대 하지 말 것

- ❌ 같은 글을 여러 블로그에 복붙(중복 콘텐츠)
- ❌ 키워드 억지로 반복(키워드 스터핑)
- ❌ 검수 없이 AI 초안 자동 공개
- ❌ 검색 트래픽만 노린 알맹이 없는 글(씬 콘텐츠)
- ❌ 자동 생성한 수백 개 페이지 한꺼번에 색인 요청

## D. 광고 배치 (애드센스)

- 콘텐츠가 광고보다 많아야 한다. 광고가 주목적인 페이지로 보이면 정책 위반.
- 첫 문단 위 광고 도배 금지. 자연스러운 본문 사이 배치.
- 자동광고는 밀도를 과하지 않게 조절.

## E. 발행 워크플로 (이 시스템 기준)

```
키워드 선정(03) → 초안 생성(brief, drafts/에 저장)
   → 사람 검수 + 보강 + 사실확인(이 체크리스트)
   → publish (기본 draft=비공개로 업로드)
   → 워드프레스에서 최종 확인 후 공개(publish)
   → 발행 후 Search Console에서 색인 요청
```

> 핵심 마인드셋: **"AI가 쓴 글을 올린다"가 아니라 "AI로 리서치·초안을
> 빨리 만들고, 내가 전문가로서 완성해 올린다."** 이 차이가 페널티와 수익을 가른다.
