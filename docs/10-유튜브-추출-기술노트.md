## 2. yt-dlp 함정

### 2-1. `--ffmpeg-location` 에는 '폴더' 가 아니라 '실행 파일 전체 경로'

증상
```
ERROR: You have requested downloading the video partially,
       but ffmpeg is not installed. Aborting
```
ffmpeg 이 **설치돼 있는데도** 이 오류가 난다. yt-dlp 는 넘겨받은 폴더에서
`ffmpeg` / `ffmpeg.exe` 라는 **이름**을 찾는다. 그런데 pip 로 들어오는
`imageio-ffmpeg` 의 파일 이름은 `ffmpeg-win-x86_64-v7.1.exe` 다.

```python
# ✗ 실패
["--ffmpeg-location", str(Path(ffmpeg_path).parent)]
# ✓ 성공 (yt-dlp 는 파일 경로도 받는다)
["--ffmpeg-location", str(ffmpeg_path)]
```
yt-dlp 내부는 파일명에 'ffmpeg' 가 포함돼 있으면 그 경로를 ffmpeg 으로
등록하므로, 이름이 달라도 전체 경로면 통한다.

### 2-2. 2026 버전은 자바스크립트 런타임을 요구한다

```
WARNING: [youtube] No supported JavaScript runtime could be found.
Only deno is enabled by default; ... has been deprecated,
and some formats may be missing
```
경고이므로 추출 자체는 대체로 되지만 일부 화질이 빠진다. 지원 런타임은
우선순위 순으로 `deno, node, quickjs, bun` 이고 **기본 탐색은 deno 뿐**이다.

```python
runtime = next((n for n in ("deno","node","quickjs","bun") if shutil.which(n)), None)
args = [] if runtime in (None, "deno") else ["--js-runtimes", runtime]
```

### 2-3. 구간만 받기 + 정확한 컷

```
--download-sections "*00:01:30.000-00:02:10.000"
--force-keyframes-at-cuts
```
`--force-keyframes-at-cuts` 를 빼면 **키프레임 단위로만** 잘린다. 실측
(키프레임 간격 10초 영상에서 5.5~9.25초 = 3.75초 요청):

| 모드 | 결과 |
|---|---|
| 경계 재인코딩(기본으로 둘 것) | **3.77초** |
| 스트림 복사 | 9.36초 (0초부터 시작) |

숏츠는 첫 1~2초가 이탈률을 결정하므로 스트림 복사 컷은 소재로 못 쓴다.

### 2-4. 결과 파일 경로 알아내기

출력 템플릿(`%(title)s` 등)을 쓰면 실제 파일명을 모른다.
```
--print-to-file after_move:filepath <임시파일> --no-simulate
```
로 파일에 적게 하고 읽는다. 실패 대비로 `out_dir.glob(f"{prefix}*")` 폴백.

### 2-5. imageio-ffmpeg 로 ffmpeg 설치를 없앨 수 있다

`pip install imageio-ffmpeg` → `imageio_ffmpeg.get_ffmpeg_exe()`.
win_amd64 휠(31MB)에 `ffmpeg-win-x86_64-v7.1.exe` 가 실제로 들어 있다.
**ffprobe 는 없다** — 구간 추출·세로 변환에는 필요 없었다.

### 2-6. 구간 1개 vs 여러 개

구간이 여러 개면 원본을 **한 번만** 받아 로컬에서 N번 자르는 쪽이 훨씬 빠르다.
캐시를 재사용할 때 주의: **이번 실행에서 받은 원본만** 정리해야 한다.
전부터 있던 캐시를 지우면 사용자 자산을 날린다(실제로 그랬다).

## 3. ffmpeg drawtext 함정 (문구 태워넣기)

### 3-1. `%` 가 있으면 그 줄이 통째로 사라진다

`"이건 '진짜' 대박: 100% 실화"` → 화면에 `"실화"` 만 남았다.
ffmpeg 은 `Stray % near ' 실화'` 를 내고 그 줄을 **조용히 버린다**.

```
drawtext=...:expansion=none      ← 필수
```
`expansion=none` 이면 `%`, `{}` 를 글자 그대로 그린다.

### 3-2. 자동 줄바꿈이 없다 + 여러 줄은 왼쪽 정렬

한 textfile 에 여러 줄을 넣으면 블록 전체만 가운데 정렬되고 각 줄은 왼쪽
정렬된다. **줄마다 drawtext 를 하나씩** 만들고 각각 `x=(w-text_w)/2` 를 주면
줄별로 가운데 정렬된다.

### 3-3. 자동 크기 조절이 없다 → 글자가 잘려 나간다

한글은 글자 폭이 글자 크기와 거의 같다. 72px × 16자 = 1152px > 1080px 이라
**16자만 넘어도 좌우가 잘린다.** 폭을 추정해 크기를 고른다.

```python
def char_width(ch, size):       # 한글·한자·가나는 정사각형, 알파벳은 절반
    wide = 0xAC00 <= ord(ch) <= 0xD7A3 or 0x4E00 <= ord(ch) <= 0x9FFF or ...
    return size * (1.0 if wide else 0.55)
# 가장 긴 줄이 (가로폭 - 여백) 안에 들어오는 크기를 위에서부터 찾는다
```
띄어쓰기 없이 긴 말은 강제로 잘라 넘겨야 한다.

### 3-4. 문구는 `textfile=` 로 넘긴다

따옴표·콜론이 섞인 문구를 필터 인자에 인라인으로 넣으면 이스케이프가 지옥이다.
파일로 넘기면 내용은 파싱되지 않아 안전하다(단 3-1 의 `%` 는 별개 문제).

### 3-5. 윈도우 경로 이스케이프

필터 인자에서 `C:\` 의 콜론이 인자 구분자와 충돌한다.
```python
f"'{str(path).replace(chr(92), '/').replace(':', r'\:')}'"   # 'C\:/Windows/Fonts/malgun.ttf'
```
한글 폰트 후보: 윈도우 `malgunbd.ttf`/`malgun.ttf`, 맥
`AppleSDGothicNeo.ttc`, 리눅스 나눔고딕·`wqy-zenhei.ttc`.
마지막 수단으로 `fc-match -f %{file} :lang=ko`.

## 4. 9:16 세로 변환 (숏츠 규격)

유튜브는 **정사각형보다 세로로 길고 3분 이하**인 영상만 숏츠로 인식한다.
가로 16:9 를 그대로 올리면 일반 영상이 된다. 출력은 1080×1920, H.264 + AAC,
`-movflags +faststart`.

| 방식 | 필터 요지 | 특징 |
|---|---|---|
| 흐린 배경 | `split` → 배경 축소·blur·확대 + 원본 `decrease` 로 `overlay` | 원본이 안 잘림. 기본값으로 적합 |
| 가운데 크롭 | `scale=...:increase, crop=1080:1920` | 꽉 차지만 좌우 잘림. **원본이 저화질이면 확대되어 흐려진다** |
| 검은 여백 | `scale=...:decrease, pad=1080:1920:-1:-1` | 화면 정보가 중요할 때 |

### 배경 블러는 축소 → 블러 → 확대

1080×1920 에서 바로 `gblur=sigma=28` 하면 30초 클립에 **22초**가 걸린다.
1/8 로 줄여 `gblur=sigma=6` 후 확대하면 **10초**. 결과는 육안으로 거의 같다
(어차피 흐린 배경이고 확대 자체가 한 번 더 부드럽게 만든다).

### 문구 위치

숏츠 화면 맨 위·아래는 유튜브 UI(제목·구독·좋아요)가 덮는다. 위쪽은
`y≈260`, 아래쪽은 `y≈H-620` 정도로 안쪽에 넣는다.

## 5. 자막(VTT) 파싱

유튜브 자동 생성 자막에는 두 가지 함정이 있다.

**① 롤링 반복** — 같은 문장을 한 단어씩 늘려가며 여러 번 내보낸다. 그대로
쓰면 프롬프트가 몇 배로 부풀고 모델도 헷갈린다. 앞 줄이 현재 줄의 prefix 면
늘어난 부분만 남긴다.

**② 큐 첫 줄의 공백** — 타임스탬프 다음 줄이 공백 한 칸인 경우가 있다.
"빈 줄이면 큐 끝" 으로 처리하면 **첫 자막을 통째로 날린다.** 앞머리의 빈 줄은
건너뛰고, 내용을 하나라도 모은 뒤의 빈 줄에서 끝낸다.

```
00:00:00.030 --> 00:00:03.270 align:start position:0%
                                    ← 공백 한 칸 (여기서 멈추면 안 된다)
안녕하세요<00:00:00.719><c> 오늘은</c>
```

인라인 태그(`<c>`, `<00:00:01.500>`) 제거와 HTML 엔티티(`&quot;`) 복원도 필요.

## 6. Gradio 6 (노코드 UI)

- `head` / `theme` 는 `Blocks(...)` 에서 **`launch(...)` 로 이동**했다.
  `show_api` 인자는 제거됐다.
- **브라우저에서 읽은 값을 파이썬 콜백에 넣기**: 입력칸의 네이티브 setter 로
  value 를 설정한 뒤 `input` 이벤트를 dispatch 하면 Svelte 가 인식한다.
  ```js
  const el = document.querySelector('#box_start textarea, #box_start input');
  const proto = el.tagName === 'TEXTAREA' ? HTMLTextAreaElement : HTMLInputElement;
  Object.getOwnPropertyDescriptor(proto.prototype, 'value').set.call(el, text);
  el.dispatchEvent(new Event('input', { bubbles: true }));
  ```
- 이걸로 **유튜브 IFrame Player API** 의 `getCurrentTime()` 을 읽어 시작·끝
  입력칸을 채울 수 있다. "영상 보면서 버튼으로 구간 잡기" 가 가능해진다.
  (`enablejsapi=1`, `onYouTubeIframeAPIReady` 를 Promise 로 감싸 대기)
- 진행 상황은 제너레이터 `yield` 로 흘린다. 단 **경고를 yield 한 직후 다음
  메시지를 yield 하면 순식간에 덮여 보이지 않는다.** 한 메시지에 합쳐야 한다.
- 긴 작업 실패 시 오류 원문 대신 "무엇을 하면 되는지" 로 번역해 보여주고,
  원문은 `<details>` 로 접어 함께 준다.

## 7. 검증 기법 (이 환경에서 유용했던 것)

**컷 지점이 정확한지 → PSNR 비교.** 원본에서 같은 구간을 뜬 것과 결과물을
비교한다.

| 비교 | PSNR |
|---|---|
| 원본 10초부터 vs 결과물 | **43.4dB** (사실상 동일) |
| 원본 9초부터 | 18.0dB |
| 원본 15초부터 | 13.5dB |

```bash
ffmpeg -ss 10 -t 15 -i full.mp4 -i clip.mp4 \
  -lavfi "[0:v]setpts=PTS-STARTPTS[a];[1:v]setpts=PTS-STARTPTS[b];[a][b]psnr" -f null -
```
`-v error` 로는 psnr 요약이 안 보인다(info 레벨).

**문구·레이아웃 → 프레임 뽑아 눈으로 본다.** `ffmpeg -ss N -i out.mp4
-frames:v 1 frame.png` 후 이미지를 직접 확인. `%` 로 글자가 사라진 버그는
단위 테스트로는 절대 못 잡았고 이 방법으로 잡았다.

**UI → Playwright 로 실제 브라우저 구동.** 유튜브가 막힌 환경이라
`page.route("**://*.youtube.com/**", abort)` 로 요청을 끊어 대기를 막고,
`probe` 나 다운로드 함수만 가짜로 끼워 넣어 나머지 실제 코드를 통과시켰다.
`wait_until="networkidle"` 은 차단 환경에서 타임아웃 난다 →
`"domcontentloaded"` + 명시적 대기.

## 8. 윈도우 배포에서 실제로 겪은 것

- **브라우저가 GitHub zip 을 막는다** ("안전하지 않은 다운로드 링크").
  리디렉션은 정상(HTTPS→codeload)이므로 저장소 문제가 아니다. PowerShell
  `Invoke-WebRequest` 로 받는 `업데이트.bat` 을 두어 브라우저를 우회했다.
  구버전 윈도우 대비로 `[Net.ServicePointManager]::SecurityProtocol = Tls12`
  를 명시하고 `$ProgressPreference='SilentlyContinue'` 로 속도를 확보한다.
- 배치 파일은 **CRLF** 여야 한다(`.gitattributes` 에 `*.bat text eol=crlf`).
  `chcp 65001` 로 한글 출력.
- 실행 중인 `.bat` 은 한 줄씩 읽히므로 **자기 자신을 덮어쓰면 안 된다.**
- 설치가 조용히 실패하는 것을 막으려면 끝에서
  `python -c "import gradio, yt_dlp, imageio_ffmpeg"` 로 실제 import 확인.
- **오류 안내를 부분 문자열로 매칭하면 원인을 가린다.** "ffmpeg" 만 보고
  "설치 안 됨" 으로 안내하다가, 실제로는 ffmpeg 이 실행되다 실패한 경우를
  며칠 동안 오진했다. 구체적인 문구부터 매칭하고, 진단 화면(`ffmpeg -version`
  실제 실행, 경로, 버전, 여유 공간)을 따로 두는 것이 훨씬 빨랐다.

## 9. 저작권

남의 영상을 잘라 그대로 올리면 저작권 클레임·채널 경고 대상이다. 도구는
① 내 영상 ② CC 라이선스 영상(`--info` 의 license 확인) ③ 해설·자막·재구성이
들어간 변형 콘텐츠를 전제로 만들었다. 원본 재업로드 목적이면 유튜브가
공식 제공하는 "리믹스 → 숏츠로 편집"(자동 출처 표기, 60초)이 안전하다.
